# Game Audio Files

Place your audio files here. The game will automatically load them if they exist.
If SE files are missing, the game will use built-in synthesizer sounds.

## BGM
- `bgm_main.mp3` : Main game loop music.

## Sound Effects (SE)
- `se_shoot.mp3` : Player shooting sound.
- `se_hit.mp3` : Enemy hit/explosion sound.
- `se_powerup.mp3` : Powerup pickup sound.
- `se_damage.mp3` : Player damaged sound.
- `se_gameover.mp3` : Game over jingle.
